Pen Pal 2.1.1

- Fixes closing. Pen Pal could freeze when you closed the window, and on some PCs it could crash right after opening.
- Pen Pal now keeps a log of the current run and the one before (pen-pal-log.txt in your data folder), so if something goes wrong there is a record of why. It never contains poem text.
- Every build now opens the real window on Windows and tests the title bar, resizing and closing before it is released.

Updating from 2.1.0: use Settings, Check for updates. 2.1.0 has the closing bug, so after you click "Restart and update" the new version opens but the old window may freeze. Close it (Windows will offer "Close the program"). Nothing is lost; your edits were already saved.
